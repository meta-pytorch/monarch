pub type ReplyFuture = Pin<Box<dyn Future<Output = PyResult<Py<PyAny>>> + Send + 'static>>;
Expand description

A Rust future that waits for endpoint replies and converts them into a Python value, or returns a Python error. Rust callers can await it directly without constructing a Python Future.

For call, call_one and choose, this future owns the reply receiver. Dropping the Rust future closes its reply port; it does not cancel the already-sent request.

Stream items share the stream’s receiver. Dropping an unobserved item leaves queued replies untouched. The reply port closes only when the last owner of that shared receiver drops it.
