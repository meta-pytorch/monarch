9//! TCP implementation of the [`Net`] transport seam — the cross-region fallback.
10//!
11//! QUIC runs over UDP, which is silently packet-filter-dropped across regions, so a
12//! devserver can only reach same-region QUIC workers. A TLS-over-TCP flow is what the
13//! cross-region enforcer clears, so `tcp://` reaches workers in any region. It reuses
14//! the same TLS material as quic (`MM_QUIC_CERT`/`MM_QUIC_KEY`/`MM_QUIC_CA`). The client
15//! verifies the server certificate against the CA for the fixed name [`SERVER_NAME`],
16//! while the server verifies the client's `clientAuth` certificate against the CA.
17//!
18//! ## kTLS, with a userspace fallback
19//!
20//! When the kernel supports it, every socket is upgraded to **kTLS** immediately after
21//! its rustls handshake: the negotiated secrets are handed to the kernel (via the
22//! `ktls` crate), so the AES-GCM record crypto runs in-kernel and the data path keeps
23//! TSO — one sender core can then drive tens of Gbps, unlike userspace TLS which is
24//! per-connection-core-bound. Both configs enable secret extraction so the keys can be
25//! exported, and the `CorkStream` wrapper lets `ktls` drain rustls' buffered records
26//! cleanly at the handoff.
27//!
28//! kTLS is a purely *local* optimization — the wire bytes are identical TLS either way,
29//! and the two ends decide independently — so a host whose kernel lacks the TLS ULP
30//! (the `tls` module) simply keeps userspace `tokio-rustls`. We [`probe_tls_ulp`] once
31//! per process and route every handshake to the kTLS or the userspace path accordingly,
32//! so a kTLS-less host never wastes a connection discovering it the hard way (this
33//! transport is already sensitive to connect-time waste at high fan-out). A kTLS setup
34//! that fails at runtime latches the whole process to userspace ([`disable_ktls`]) so
35//! we don't retry a path the kernel has already refused. `MM_TCP_KTLS=0` forces the
36//! userspace path outright (for debugging or to sidestep a flaky kernel). The three
37//! stream flavors — in-kernel and the two userspace half-types — are unified behind
38//! [`TlsStream`], over which the pairing prefix and every generic frame flow
39//! identically.
40//!
41//! Everything protocol-independent — establishment, heartbeats (on their own stream),
42//! matching serves to joins, side channels, retry/backoff, shutdown — lives in
43//! [`crate::net_transport`], generic over [`Net`]. This module supplies only the raw
44//! networking. The command loop drives tcp as `NetTransport<Tcp>` (aliased
45//! `TcpTransport` in [`crate::ctx`]).
46//!
47//! ## Streams: one socket each, opened on demand and paired by index
48//!
49//! A QUIC connection multiplexes its streams (data + heartbeat) on one transport
50//! connection; TCP has no multiplexing, so each stream is its own TLS-over-TCP socket.
51//! A plain socket can only be opened from the dialing side, so a tcp connection is
52//! *directional*: the dialer's [`NetConn::stream`] dials a fresh socket, the acceptor's
53//! awaits one. Each socket the dialer opens carries a `(connection_id, stream_index)`
54//! prefix. Many logical connections share one listening socket, so a single listener
55//! demux pairs each accepted socket with the acceptor-side `stream` request naming the
56//! same `(connection_id, index)` — a matcher per pair, dropped as soon as the two halves
57//! meet. A socket for stream index 0 (the connection's first stream) surfaces the
58//! connection out of [`Net::accept`]; later sockets (the heartbeat stream, or data
59//! streams for striping) just pair against their requests.
60//!
61//! Streams are opened lazily and per index — nothing is pre-opened at connect time — so
62//! a message-only side channel opens exactly one socket, and the transport can request a
63//! heartbeat or additional data stream whenever it needs one. `priority` is ignored:
64//! tcp has no per-stream send priority.
65//!
66//! ## No transport keepalive
67//!
68//! A root opens a huge number of connections, so — exactly like the quic side, which
69//! disables quinn's PING keep-alive and idle timeout — these sockets must carry **zero**
70//! periodic per-connection traffic of their own. We never enable TCP keepalive
71//! (`SO_KEEPALIVE`, off by default and left off), and TCP has no idle timeout, so an
72//! idle connection stays open sending nothing. Liveness is entirely the heartbeat
73//! subsystem's job (its own stream, and delegated so the root's steady-state cost is
74//! bounded); a link with no heartbeat obligation — e.g. a delegated one — is genuinely
75//! silent, which is what lets the connection count scale.
76//!
77//! ## Throughput tuning
78//!
79//! The fast settings that are *safe* to enable everywhere are on by default; the ones
80//! whose cost or policy impact scales with the connection count are left opt-in.
81//!
82//! On by default (safe regardless of scale):
83//!
84//! - `TCP_NODELAY` — always on: framing flushes per frame, so Nagle would only add
85//!   latency.
86//! - Congestion control defaults to **BBR**, pinned with `TCP_CONGESTION` *after* the
87//!   connection is up — matching the quic transport, which pins BBR unconditionally.
88//!   The post-connect timing is deliberate: cross-region flows at Meta have a NetEdit
89//!   cgroup eBPF `sockops` force their own CUBIC variant at connect time, overriding
90//!   any pre-connect `setsockopt`; a post-connect set sticks. The set is best-effort,
91//!   so a host without the `tcp_bbr` module simply keeps the kernel default. Override
92//!   with `MM_TCP_CONGESTION` (e.g. `cubic`, or empty to pin nothing).
93//! - Listen backlog and `SO_REUSEADDR` on the listener — robustness with negligible
94//!   cost.
95//!
96//! Opt-in (unset ⇒ OS default), because a fixed kernel socket-buffer size both
97//! *disables* Linux's per-socket buffer autotuning and — since tcp uses one socket per
98//! stream per connection, and a root holds a huge number of connections — multiplies
99//! that fixed cost across every socket. Autotuning is the better default at scale;
100//! these are for reproducing the cross-region bandwidth ceilings in a bench:
101//!
102//! - `MM_TCP_SNDBUF_BYTES` / `MM_TCP_RCVBUF_BYTES` — kernel socket-buffer sizes,
103//!   set *before* connect/bind so TCP window scaling is negotiated for the enlarged
104//!   window (accepted sockets inherit the listener's scale). Requested with the
105//!   privileged `SO_*BUFFORCE` options (which bypass `net.core.{r,w}mem_max` under
106//!   `CAP_NET_ADMIN`, e.g. as root on MAST) with a fall back to the ordinary setters
107//!   otherwise.

173/// The congestion-control algorithm to pin after connect. Defaults to BBR — matching
174/// the quic transport, which pins BBR unconditionally: it holds a higher steady rate
175/// than CUBIC across the light loss of a high-RTT cross-region path (quinn#2262: CUBIC
176/// stalls at ~1 MiB cwnd where BBR reaches the BDP) and is ~neutral on the lossless
177/// intra-cluster fabric. Best-effort — if the `tcp_bbr` module is not loaded the set
178/// fails and the kernel default stays (see [`set_congestion`]). Override the algorithm
179/// with `MM_TCP_CONGESTION` (e.g. `cubic` to pin the classic default); an empty
180/// `MM_TCP_CONGESTION=` pins nothing at all, leaving whatever the kernel/NetEdit picks.
181fn congestion() -> Option<String> {
182    match std::env::var("MM_TCP_CONGESTION") {
183        Ok(name) if name.is_empty() => None, // explicit opt-out: pin nothing
184        Ok(name) => Some(name),
185        Err(_) => Some("bbr".to_owned()), // default
186    }
187}

205/// Enlarge a socket's kernel send/recv buffers, best-effort, *before* connect/bind
206/// so TCP window scaling is negotiated for the enlarged window. Tries the privileged
207/// `SO_*BUFFORCE` options first — these bypass the `net.core.{r,w}mem_max` ceiling
208/// under `CAP_NET_ADMIN` (e.g. running as root on MAST) — and falls back to the
209/// ordinary setters (which the kernel clamps to that ceiling) when not permitted. A
210/// no-op for a buffer whose env knob is unset.
211fn set_buffers(fd: RawFd) {
212    if let Some(bytes) = sndbuf_bytes() {
213        set_buffer(fd, libc::SO_SNDBUFFORCE, libc::SO_SNDBUF, bytes);
214    }
215    if let Some(bytes) = rcvbuf_bytes() {
216        set_buffer(fd, libc::SO_RCVBUFFORCE, libc::SO_RCVBUF, bytes);
217    }
218}
219
220fn set_buffer(fd: RawFd, force_opt: libc::c_int, opt: libc::c_int, bytes: usize) {
221    let size = bytes.min(i32::MAX as usize) as libc::c_int;
222    let len = std::mem::size_of::<libc::c_int>() as libc::socklen_t;
223    // SAFETY: `fd` is a valid socket for the call's duration; the option value is an
224    // `int` of length `len`, as required by SO_*BUF{,FORCE}.
225    let forced = unsafe {
226        let value = std::ptr::from_ref(&size).cast::<libc::c_void>();
227        libc::setsockopt(fd, libc::SOL_SOCKET, force_opt, value, len)
228    };
229    if forced != 0 {
230        // SAFETY: as above; the ordinary setter is clamped by the kernel.
231        unsafe {
232            let value = std::ptr::from_ref(&size).cast::<libc::c_void>();
233            libc::setsockopt(fd, libc::SOL_SOCKET, opt, value, len);
234        }
235    }
236}

238/// Apply the post-connect socket tuning to an established socket: `TCP_NODELAY` (always
239/// on — framing flushes per frame, so Nagle would only add latency) and the pinned
240/// congestion-control algorithm (BBR by default; see [`congestion`]). Both are
241/// best-effort. The congestion set must run *after* connect — see the module docs on
242/// the NetEdit connect-time override.
243fn tune_established(stream: &TcpStream) {
244    let _ = stream.set_nodelay(true);
245    set_congestion(stream.as_raw_fd());
246}
247
248/// Pin the congestion-control algorithm on an established connection, if
249/// `MM_TCP_CONGESTION` / `MM_TCP_BBR` requested one. Best-effort: a failure (e.g. the
250/// `tcp_bbr` module is not loaded) leaves the kernel default in place.
251fn set_congestion(fd: RawFd) {
252    let Some(name) = congestion() else {
253        return;
254    };
255    // SAFETY: `fd` is a valid connected TCP socket; `name` bytes are a valid buffer
256    // of `name.len()`, the form TCP_CONGESTION expects (a non-terminated string).
257    unsafe {
258        libc::setsockopt(
259            fd,
260            libc::IPPROTO_TCP,
261            libc::TCP_CONGESTION,
262            name.as_ptr().cast::<libc::c_void>(),
263            name.len() as libc::socklen_t,
264        );
265    }
266}

275fn load_tls() -> anyhow::Result<TlsConfig> {
276    let tls::Config {
277        mut server,
278        mut client,
279    } = tls::Config::load()?;
280
281    // Both configs enable secret extraction so the negotiated keys can be handed to
282    // the kernel for kTLS (see the module docs and [`client_ktls`]/[`server_ktls`]).
283    server.enable_secret_extraction = true;
284    client.enable_secret_extraction = true;
285
286    Ok(TlsConfig {
287        server: Arc::new(server),
288        client: Arc::new(client),
289    })
290}

292/// Parse a `tcp://host:port` (or bare `host:port`) url into a socket address.
293fn parse_addr(url: &str) -> anyhow::Result<SocketAddr> {
294    let authority = url.strip_prefix("tcp://").unwrap_or(url);
295    authority
296        .parse::<SocketAddr>()
297        .map_err(|err| anyhow::anyhow!("invalid tcp address {authority:?}: {err}"))
298}

300/// A fresh, effectively-unique connection id used to pair the sockets of one logical
301/// connection at the listener. 128 random bits (two independently-seeded `RandomState`
302/// hashes) — a collision would require two live connections to a single server to draw
303/// the same 128-bit id, which is negligible.
304fn new_connection_id() -> u128 {
305    let hi = std::collections::hash_map::RandomState::new().hash_one(0xA5u8) as u128;
306    let lo = std::collections::hash_map::RandomState::new().hash_one(0x5Au8) as u128;
307    (hi << 64) | lo
308}

310/// Write the socket-pairing prefix (`connection_id` then `stream_index`) that lets the
311/// listener demux group the sockets of one logical connection and route each to its
312/// stream-index request. Precedes every generic frame on a dialed socket.
313async fn write_pairing_prefix<W: AsyncWrite + Unpin>(
314    writer: &mut W,
315    connection_id: u128,
316    stream_index: usize,
317) -> io::Result<()> {
318    writer.write_all(&connection_id.to_le_bytes()).await?;
319    writer
320        .write_all(&(stream_index as u16).to_le_bytes())
321        .await?;
322    writer.flush().await
323}
324
325/// Read the socket-pairing prefix written by [`write_pairing_prefix`], as
326/// `(connection_id, stream_index)`. `None` on EOF or a short read (a peer that spoke a
327/// bad dialect — the socket is dropped).
328async fn read_pairing_prefix<R: AsyncRead + Unpin>(reader: &mut R) -> Option<(u128, usize)> {
329    let mut id = [0u8; 16];
330    reader.read_exact(&mut id).await.ok()?;
331    let mut index = [0u8; 2];
332    reader.read_exact(&mut index).await.ok()?;
333    Some((u128::from_le_bytes(id), u16::from_le_bytes(index) as usize))
334}

336/// A TLS-over-TCP stream in one of three flavors, unified so framing (and the pairing
337/// prefix) drives them identically: an in-kernel [`KtlsStream`] on a host with the TLS
338/// ULP, or a userspace `tokio-rustls` stream (server- or client-side) otherwise. See
339/// the module docs on the kTLS fallback.
340pub(crate) enum TlsStream {
341    Ktls(KtlsStream<TcpStream>),
342    Server(ServerTlsStream<TcpStream>),
343    Client(ClientTlsStream<TcpStream>),
344}

357    }

390/// Set once a kTLS setup has failed at runtime (or the up-front probe found the TLS ULP
391/// missing): from then on every handshake takes the userspace path. Starts `false`; the
392/// first [`use_ktls`] call resolves the probe into it.
393static KTLS_DISABLED: AtomicBool = AtomicBool::new(false);
394
395/// Whether to attempt kTLS for the next handshake. `true` until we learn the kernel
396/// can't do it — either because `MM_TCP_KTLS=0` opted out, from the one-time
397/// [`probe_tls_ulp`] (resolved on first call), or from a runtime failure that called
398/// [`disable_ktls`].
399fn use_ktls() -> bool {
400    static PROBED: OnceLock<()> = OnceLock::new();
401    PROBED.get_or_init(|| {
402        if matches!(
403            std::env::var("MM_TCP_KTLS").as_deref(),
404            Ok("0") | Ok("false")
405        ) {
406            disable_ktls("opted out via MM_TCP_KTLS");
407        } else if !probe_tls_ulp() {
408            disable_ktls("kernel TLS ULP (tls module) not available");
409        }
410    });
411    !KTLS_DISABLED.load(Ordering::Relaxed)
412}
413
414/// Latch kTLS off for the whole process, logging the reason once. Called on a runtime
415/// kTLS setup failure so the connection retry — and every later handshake — uses
416/// userspace TLS instead of re-attempting a path the kernel refused.
417fn disable_ktls(reason: &str) {
418    if !KTLS_DISABLED.swap(true, Ordering::Relaxed) {
419        eprintln!("MM_TCP kTLS disabled, falling back to userspace TLS: {reason}");
420    }
421}

423/// Probe whether the kernel exposes the TLS upper-layer protocol (kTLS), by trying to
424/// set the `tls` ULP on a throwaway TCP socket. A missing kernel module fails with
425/// `ENOENT`; any other outcome — including `ENOTCONN`, since we deliberately don't
426/// connect the socket — means the module is present. Cheap and connection-free, so a
427/// kTLS-less host learns its fate without sacrificing a real connection.
428fn probe_tls_ulp() -> bool {
429    // SAFETY: a plain `socket()`/`setsockopt()`/`close()` sequence. `fd` is valid
430    // between its creation and close; the option value is the 3-byte string `tls` of
431    // the matching length, as `TCP_ULP` expects (a non-terminated name).
432    unsafe {
433        let fd = libc::socket(libc::AF_INET, libc::SOCK_STREAM, 0);
434        if fd < 0 {
435            return false;
436        }
437        let name = b"tls";
438        let ret = libc::setsockopt(
439            fd,
440            libc::SOL_TCP,
441            libc::TCP_ULP,
442            name.as_ptr().cast::<libc::c_void>(),
443            name.len() as libc::socklen_t,
444        );
445        let errno = (ret != 0).then(|| std::io::Error::last_os_error().raw_os_error());
446        libc::close(fd);
447        !matches!(errno, Some(Some(libc::ENOENT)))
448    }
449}

451/// Run the client rustls handshake over `tcp`, then hand back a [`TlsStream`]. When
452/// [`use_ktls`] is set the socket is wrapped in a `CorkStream` and upgraded to kTLS
453/// (the cork lets `ktls` drain rustls' buffered records cleanly at the handoff, and any
454/// decrypted-but-unconsumed app data is re-injected for the caller); a kTLS setup that
455/// fails latches the process to userspace so the connection's retry succeeds there.
456/// Otherwise the plain userspace `tokio-rustls` stream is returned directly.
457async fn client_tls(
458    connector: &TlsConnector,
459    server_name: ServerName<'static>,
460    tcp: TcpStream,
461) -> anyhow::Result<TlsStream> {
462    if use_ktls() {
463        let stream = connector.connect(server_name, CorkStream::new(tcp)).await?;
464        return match ktls::config_ktls_client(stream).await {
465            Ok(ktls) => Ok(TlsStream::Ktls(ktls)),
466            Err(err) => {
467                disable_ktls(&format!("client kTLS setup failed: {err}"));
468                Err(anyhow::anyhow!("client kTLS setup failed: {err}"))
469            }
470        };
471    }
472    let stream = connector.connect(server_name, tcp).await?;
473    Ok(TlsStream::Client(stream))
474}
475
476/// Run the server rustls handshake over `tcp`, then hand back a [`TlsStream`] (see
477/// [`client_tls`] for the kTLS/userspace split).
478async fn server_tls(acceptor: &TlsAcceptor, tcp: TcpStream) -> anyhow::Result<TlsStream> {
479    if use_ktls() {
480        let stream = acceptor.accept(CorkStream::new(tcp)).await?;
481        return match ktls::config_ktls_server(stream).await {
482            Ok(ktls) => Ok(TlsStream::Ktls(ktls)),
483            Err(err) => {
484                disable_ktls(&format!("server kTLS setup failed: {err}"));
485                Err(anyhow::anyhow!("server kTLS setup failed: {err}"))
486            }
487        };
488    }
489    let stream = acceptor.accept(tcp).await?;
490    Ok(TlsStream::Server(stream))
491}

498impl Tcp {

525/// The single demux for a bound tcp server. Many logical connections share one listening
526/// socket, so it pairs each accepted socket with the [`TcpStreamRequest`] naming the same
527/// `(connection_id, index)` — one [`Matcher`] per pair, removed the moment its two halves
528/// meet, so a healthy connection leaves nothing behind (no per-connection coroutine, no
529/// live map). A socket for stream index 0 is a connection's first stream (it carries the
530/// preamble and arrives once), so it surfaces a fresh [`TcpConn`] out of [`Net::accept`].
531///
532/// Each socket's TLS handshake + prefix read runs in its own task — so a slow handshake
533/// doesn't head-of-line-block accept — then lands on `sockets`. Requests from every
534/// acceptor connection's `stream` calls share `requests`. The loop holds no lock and
535/// never awaits while touching the matchers, so sockets and requests never block each
536/// other.
537async fn listener_demux(
538    listener: TcpListener,
539    acceptor: TlsAcceptor,
540    new_conns: mpsc::UnboundedSender<TcpConn>,
541) {
542    // Requests from every acceptor connection's `stream` calls. The sender is cloned into
543    // each surfaced connection; the loop keeps `requests_tx` too, so `requests.recv()`
544    // never closes on its own.
545    let (requests_tx, mut requests) = mpsc::unbounded_channel::<TcpStreamRequest>();
546    // Handshaked sockets from the per-socket handshake tasks.
547    let (sock_tx, mut sockets) = mpsc::unbounded_channel::<(SocketAddr, u128, usize, TlsStream)>();
548    // For each (connection_id, index): the socket or the request that arrived first,
549    // parked until its partner shows up. An entry lives only while a half is waiting.
550    let mut matchers: HashMap<(u128, usize), Matcher<TcpStreamRequest, TlsStream>> = HashMap::new();
551    loop {
552        tokio::select! {
553            accepted = listener.accept() => {
554                let Ok((tcp, peer)) = accepted else {
555                    continue; // transient accept error; the listener stays open
556                };
557                // The connection is up (accept returned), so pin nodelay/congestion now;
558                // the buffer window scale was inherited from the listening socket.
559                tune_established(&tcp);
560                let acceptor = acceptor.clone();
561                let sock_tx = sock_tx.clone();
562                tokio::task::spawn_local(async move {
563                    let Ok(mut stream) = server_tls(&acceptor, tcp).await else {
564                        return; // TLS/kTLS handshake failed
565                    };
566                    let Some((cid, index)) = read_pairing_prefix(&mut stream).await else {
567                        return; // bad/short prefix
568                    };
569                    let _ = sock_tx.send((peer, cid, index, stream));
570                });
571            }
572            sock = sockets.recv() => {
573                let Some((peer, cid, index, stream)) = sock else { continue; };
574                let key = (cid, index);
575                if matchers
576                    .entry(key)
577                    .or_insert_with(Matcher::new)
578                    .push_right(stream, fulfill_tcp)
579                    .is_some()
580                {
581                    matchers.remove(&key);
582                }
583                // Index 0 is the connection's first stream; surface it once, here.
584                if index == 0 {
585                    let conn = TcpConn::Acceptor {
586                        remote: peer,
587                        connection_id: cid,
588                        requests: requests_tx.clone(),
589                    };
590                    if new_conns.send(conn).is_err() {
591                        return; // transport gone
592                    }
593                }
594            }
595            req = requests.recv() => {
596                // We hold `requests_tx`, so recv never returns None; guard anyway.
597                let Some(req) = req else { return; };
598                let key = (req.connection_id, req.index);
599                if matchers
600                    .entry(key)
601                    .or_insert_with(Matcher::new)
602                    .push_left(req, fulfill_tcp)
603                    .is_some()
604                {
605                    matchers.remove(&key);
606                }
607            }
608        }
609    }
610}

612impl Net for Tcp {
613    type Dialer = TcpDialer;
614    type Listener = TcpListenerHandle;
615    type Conn = TcpConn;
616
617    fn create(_runtime: Option<Handle>) -> anyhow::Result<Self> {
618        // Ignored: kTLS/rustls crypto runs in the stream poll (the read/write syscall),
619        // not a background driver, so it follows whichever task polls the stream. The
620        // generic transport places those data coroutines on the runtime instead.
621        Ok(Self { tls: None })
622    }
623
624    fn parse_addr(url: &str) -> anyhow::Result<SocketAddr> {
625        parse_addr(url)
626    }
627
628    fn dialer(&mut self, _addr: SocketAddr) -> anyhow::Result<TcpDialer> {
629        let connector = TlsConnector::from(self.tls()?.client.clone());
630        let server_name = ServerName::try_from(SERVER_NAME)
631            .map_err(|err| anyhow::anyhow!("tcp server name: {err}"))?
632            .to_owned();
633        Ok(TcpDialer {
634            connector,
635            server_name,
636        })
637    }
638
639    fn bind(&mut self, addr: SocketAddr) -> anyhow::Result<TcpListenerHandle> {
640        log_tuning_once();
641        let acceptor = TlsAcceptor::from(self.tls()?.server.clone());
642        // Build the listener socket directly so the kernel buffers can be enlarged
643        // *before* bind (so the window scale accepted sockets inherit reflects the
644        // enlarged window), then bind and listen — none of which awaits.
645        let socket = if addr.is_ipv6() {
646            TcpSocket::new_v6()?
647        } else {
648            TcpSocket::new_v4()?
649        };
650        set_buffers(socket.as_raw_fd());
651        socket.set_reuseaddr(true)?;
652        socket.bind(addr)?;
653        let listener = socket.listen(LISTEN_BACKLOG)?;
654        // Spawn the demux on the command-loop LocalSet (bind is called from it). It owns
655        // the listener and pairs accepted sockets to stream requests, surfacing new
656        // connections on `new_tx`.
657        let (new_tx, new_rx) = mpsc::unbounded_channel();
658        tokio::task::spawn_local(listener_demux(listener, acceptor, new_tx));
659        Ok(TcpListenerHandle {
660            new_conns: Mutex::new(new_rx),
661        })
662    }
663
664    async fn accept(listener: &TcpListenerHandle) -> Option<TcpConn> {
665        listener.new_conns.lock().await.recv().await
666    }
667
668    async fn connect(dialer: &TcpDialer, addr: SocketAddr) -> Option<TcpConn> {
669        // Lazy: no socket is opened here. Each stream dials its own socket on demand (see
670        // `TcpConn::stream`), so a tcp join's reachability is proven by the first stream
671        // call, not here. Just mint the id that groups this connection's sockets.
672        Some(TcpConn::Dialer {
673            dialer: dialer.clone(),
674            addr,
675            connection_id: new_connection_id(),
676        })
677    }
678
679    /// tcp opens an OS socket plus a TLS handshake per stream, so it needs a much smaller
680    /// default than quic: an unthrottled connect storm at high fan-out leaves stragglers
681    /// whose first socket never finishes handshaking (seen as the root's `only N-1/N
682    /// workers connected` aborts). 128 has proven safe through a full 65k-worker sweep;
683    /// raise with `MM_QUIC_MAX_CONCURRENT_CONNECTS` if a run needs faster connect ramp.
684    /// (The throttle covers the first stream's dial; the heartbeat and any data streams
685    /// open later, naturally staggered.)
686    fn default_connect_concurrency() -> Option<usize> {
687        Some(128)
688    }
689}

691/// The send/recv halves of one paired tcp stream.
692type TcpHalves = (WriteHalf<TlsStream>, ReadHalf<TlsStream>);
693
694/// A [`NetConn::stream`] request from an acceptor connection to the listener demux: which
695/// `(connection_id, index)` socket it wants, and the one-shot the demux fulfils with the
696/// paired socket's halves. (tcp has no per-stream priority, so none is carried.)
697pub(crate) struct TcpStreamRequest {
698    connection_id: u128,
699    index: usize,
700    reply: oneshot::Sender<io::Result<TcpHalves>>,
701}
702
703/// Fulfil a request with the socket the demux paired to its `(connection_id, index)`:
704/// split the socket and send the halves back through the one-shot.
705fn fulfill_tcp(req: TcpStreamRequest, stream: TlsStream) {
706    let (recv, send) = tokio::io::split(stream);
707    let _ = req.reply.send(Ok((send, recv)));
708}
709
710/// Dial one TLS-over-TCP socket to `addr` (see the module tuning docs for the socket
711/// options). The caller ([`NetConn::stream`]) writes the pairing prefix afterwards.
712async fn dial_one(dialer: &TcpDialer, addr: SocketAddr) -> io::Result<TlsStream> {
713    log_tuning_once();
714    // Build the socket directly so the kernel buffers can be enlarged *before* connect
715    // (so window scaling is negotiated for the enlarged window), then pin
716    // nodelay/congestion once the connection is up.
717    let socket = if addr.is_ipv6() {
718        TcpSocket::new_v6()?
719    } else {
720        TcpSocket::new_v4()?
721    };
722    set_buffers(socket.as_raw_fd());
723    let tcp = socket.connect(addr).await?;
724    tune_established(&tcp);
725    client_tls(&dialer.connector, dialer.server_name.clone(), tcp)
726        .await
727        .map_err(|e| io::Error::other(format!("tcp/tls dial {addr}: {e:#}")))
728}
729
730/// One logical TCP connection, in one of two roles set at construction, and cloneable so
731/// several tasks (data reader/writer, heartbeat) can each open the streams they own. A
732/// **dialer** connection (from [`Net::connect`]) opens each requested stream by dialing a
733/// fresh socket and writing its `(connection_id, index)` prefix. An **acceptor**
734/// connection (from [`Net::accept`]) sends each request — tagged with its `connection_id`
735/// and index — to the shared [`listener_demux`], which pairs it with the matching socket.
736/// The demux keeps no per-connection state past a pending pair, so cloning the handle is
737/// free of lifecycle concerns.
738#[derive(Clone)]
739pub(crate) enum TcpConn {
740    Dialer {
741        dialer: TcpDialer,
742        addr: SocketAddr,
743        connection_id: u128,
744    },
745    Acceptor {
746        remote: SocketAddr,
747        connection_id: u128,
748        requests: mpsc::UnboundedSender<TcpStreamRequest>,
749    },
750}
751
752impl fmt::Debug for TcpConn {
753    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
754        let remote = match self {
755            TcpConn::Dialer { addr, .. } => addr,
756            TcpConn::Acceptor { remote, .. } => remote,
757        };
758        f.debug_tuple("TcpConn").field(remote).finish()
759    }
760}

762impl NetConn for TcpConn {
763    type Send = WriteHalf<TlsStream>;
764    type Recv = ReadHalf<TlsStream>;
765    type Stream = Pin<Box<dyn Future<Output = io::Result<(Self::Send, Self::Recv)>> + Send>>;
766
767    fn stream(&self, index: usize, _priority: i32) -> Self::Stream {
768        match self {
769            // Dialer: open a fresh socket for this index and tag it with the prefix.
770            TcpConn::Dialer {
771                dialer,
772                addr,
773                connection_id,
774            } => {
775                let dialer = dialer.clone();
776                let addr = *addr;
777                let connection_id = *connection_id;
778                Box::pin(async move {
779                    let mut stream = dial_one(&dialer, addr).await?;
780                    write_pairing_prefix(&mut stream, connection_id, index).await?;
781                    let (recv, send) = tokio::io::split(stream);
782                    Ok((send, recv))
783                })
784            }
785            // Acceptor: ask the demux for this (connection, index) socket and await the
786            // paired halves.
787            TcpConn::Acceptor {
788                connection_id,
789                requests,
790                ..
791            } => {
792                let connection_id = *connection_id;
793                let requests = requests.clone();
794                Box::pin(async move {
795                    let (reply, rx) = oneshot::channel();
796                    requests
797                        .send(TcpStreamRequest {
798                            connection_id,
799                            index,
800                            reply,
801                        })
802                        .map_err(|_| io::Error::other("tcp connection closed"))?;
803                    rx.await
804                        .map_err(|_| io::Error::other("tcp connection closed"))?
805                })
806            }
807        }
808    }
809}
