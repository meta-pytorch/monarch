pub fn get_cuda_device_to_ibv_devices<I: IbvDeviceImpl>() -> Result<Vec<Vec<IbvDeviceInfo>>>
Expand description

The NICs of backend I for each CUDA runtime ordinal, indexed by ordinal.

Each entry holds every NIC tied for the best path to that ordinal, in lexicographic order by name per select_optimal_ibv_devices, so an entry is empty when no NIC could be ranked against its ordinal. Errors only when the ordinals themselves cannot be enumerated, which in practice means the CUDA driver is not initialized in this process.
