RDMA configuration attributes.

Statics§

RDMA_ALLOW_TCP_FALLBACK
Allow TCP fallback when ibverbs hardware is unavailable.
RDMA_CQ_POLLER_PER_DEVICE
Whether each device gets its own completion-queue poller.
RDMA_DISABLE_IBVERBS
Disable ibverbs even when hardware is present.
RDMA_HOST_ODP
Use one implicit-ODP registration per mlx5 device for newly registered host buffers. Destination ranges receive asynchronous write advice; per-allocation host-memory registration remains the default.
RDMA_IBVERBS_TARGET
Default ibverbs device target for managers without an explicit target.
RDMA_MAX_CHUNK_SIZE_MB
Maximum chunk size in MiB for TCP-based RDMA transfers.
RDMA_MAX_NICS_PER_BUFFER
How many NICs a buffer is registered on, at most. None, the default, sets no limit: every equally good NIC serves the buffer. An empty environment value parses to None.
RDMA_MIN_STRIPE_SIZE_KB
Minimum RDMA stripe size, in KiB.
RDMA_PEER_DEVICE_AFFINITY
Which peer NICs each local NIC may pair with for a transfer.
RDMA_QPS_PER_CQ
How many queue pairs share one completion queue.
RDMA_QPS_PER_PEER
How many queue pairs to create for each local-NIC/peer/remote-NIC route.
RDMA_QP_INIT_TIMEOUT
Per-side budget for the QueuePairInitializer handshake. The timer arms once when we send EnsureQueuePair and is rearmed after we hit RTS while still waiting for the peer’s NotifyRts. If it fires the entry is tombstoned with a qp_initializer_failed so further RequestQueuePair calls for the same key surface the same error rather than hanging.
RDMA_RUNTIME_WORKER_THREADS
Worker-thread count for the shared rdma data-plane runtime, which runs RDMA actors and queue-pair worker tasks. The default is 4.
RDMA_TCP_FALLBACK_PARALLELISM
Number of parallel channels for TCP fallback transfers.
