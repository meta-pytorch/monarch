How many queue pairs to create for each local-NIC/peer/remote-NIC route.

A transfer is split into at least this many stripes, rounded up to a multiple of its NIC pair count, so a transfer over one NIC pair still uses every queue pair. Stripes take each route’s queue pairs in round robin order. RDMA_MIN_STRIPE_SIZE_KB lowers the stripe count for small transfers.
